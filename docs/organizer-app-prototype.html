Sportzy Organizer

One app for tournament and match organisation, multi-phone camera production and streaming to Streemzy. Example data only. No real cameras, video, money or network. Anything that needs an API that doesn't exist yet is labelled Assumed API.

Still open decisions

  1. Stack and repo. The UI layer is undecided. The broadcast engine (mixing, overlay, encoding) is expected to be native media code.
  2. Assumed APIs. Streemzy create-stream and ingest key, Scorezy overlay page, Scorezy match link and result callback, Federation org creation.
  3. Plans. Bought on the Sportzy website only. Free vs Pro limits here are a proposal.
  4. Turf owners (gap 16) and the test approach (gap 21) aren't shown here.
  5. Limits. 4 cameras on Pro, 2 on Free, 720p30 by default, until a real-device test.
