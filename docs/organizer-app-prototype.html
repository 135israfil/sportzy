Sportzy Organizer

One app for tournament and match organisation, multi-phone camera production and streaming to Streemzy. Mock data only. No real cameras, video or network. It is stack-neutral, so it can settle flows and screens while the media-architecture decision is still open.

Open decisions reflected here

  1. Stack. UI layer undecided. The broadcast engine (mixing, overlay compositing, encoding) is expected to be native media code.
  2. Repo. New repo still to be created.
  3. Scorezy link. The control-panel address is a placeholder until the real URL is set.
  4. Limits. The prototype assumes 4 cameras per match (adjustable on the Cameras screen) and 720p30 by default.
