Sportzy Player

One app for players to find and book turfs, register a team for tournaments, join open games and pay. Example data only. No real accounts, bookings or payments. It is stack-neutral, so it can settle flows and screens while the stack, the mobile API and the Federation sign-in flow are still being decided.

Simulate

Select slots on a venue first to see a slot taken before you hold it. Once held, nobody else can book it.

Open decisions

  1. Stack. React Native (Expo), Flutter, or native Swift + Kotlin.
  2. Repo. The existing sportzy repo, or a new one.
  3. Mobile API. The platform has no public JSON API yet. Booking rules here (holds, overlap, 24-hour refund) mirror the web.
  4. Sign-in. Native app login on Federation needs a token flow such as PKCE.
