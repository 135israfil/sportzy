# First booking

| | |
|---|---|
| **Dates** | 12 Dec 2026 – 31 Jan 2027 |
| **Objective** | Get new players to complete their first booking at an active venue. |
| **Audience** | Players near active venues |
| **Offer and message** | No cash discount. The promise: real open slots, hold while you pay, refund rule shown. |
| **Feature status** | Built. |
| **Channels** | Meta C2/C3, Google Search, venue posters (QR), Instagram |
| **Assets** | VID-03, VID-12, DES-13, DES-17, SCR turfdetail |
| **Owner** | Performance (I), Growth (B) |
| **KPI** | Cost per completed first booking; first bookings per week |
| **Success** | Stop-rule CAC met (budget_plan § 4) |
| **Kill or change if** | CAC above the stop rule for 2 weeks: move spend to posters at venues and organiser events. |
